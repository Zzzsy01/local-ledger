# 随手账 · 安卓本地记账

Kotlin + Jetpack Compose + Navigation Compose + Room，Android 8.0（API 26）及以上。

无需账号，备忘录、心愿、账目和物品存本机，日常记录离线可用。联网用于可关闭的应用更新检查；闲鱼查询由外部浏览器打开。现有网页票据工具保持独立。1.5.0 新增生活管理、账户余额/转账、离线截图识别、物品照片、桌面待办和应用锁；完整功能及参考对应见 [PDF-INTEGRATION.md](PDF-INTEGRATION.md)。安卓暂不导出票据 PDF。

## 使用

- 账单：首页按月汇总、按日显示流水；点击流水编辑，右侧操作菜单可选“删除账目”，确认删除后可撤销。“再记一笔”复制到新表单，日期改为今天，保存生成新 UUID。
- 搜索／筛选：关键词匹配备注、分类、账户；可选全部日期、所选月份或自定义开始／结束日期，并按收支、分类、账户、金额区间筛选。列表和合计使用同一条件。
- 记一笔：输入金额、选择收入或支出分类即可保存；默认今天与上次使用的账户，备注选填。
- 双主页：首次更新到 1.4.0 默认进入备忘录。顶部「备忘录／记账」一键切换，各自保留页面、列表位置和筛选。备忘录底部为「备忘录、生活、博物馆、心愿」，记账底部为「账单、报表、博物馆、工具」，设置统一在顶部齿轮；备忘录设置不显示分类、预算或账单导入。设置可选择下次启动默认打开的模式，之后不会重置选择。
- 心愿：填写想买的东西、预计价格、已攒金额和选填的理由；汇总待买预算、还需攒多少钱和进度。已攒金额由用户更新，超过单个心愿目标的部分不抵扣其他心愿；买到后归入已达成，可移回想买或确认删除。目标独立于收支、物品与账户，不自动生成账目。
- 报表：周报、月报、年报与自定义日期，支持收入／支出切换、日／月趋势图、分类环图、近六个月或全年月度柱状对比、账户分布和前 10 笔金额排行；点选趋势图或使用左右按钮查看数据点，点分类行查看环图中心金额，点击排行账目编辑。日均按所选区间天数计算，自定义趋势超过 62 天时按月汇总；自定义边界包含开始和结束当天。周报以周一至周日为一个周期。
- 分类：添加、改名、上移下移、停用。停用分类仍保留在历史账目和统计中。
- 物品：记录物品型号、类别、购入价和当前二手估值；可打开闲鱼找同款，手动填入最多 30 个可比报价，自动计算到分的平均值。该值是用户录入的挂牌参考价，不是平台自动查询的市场成交均价。物品估值独立于收支，不计入收入或账户余额。
- 设置 → 数据与备份：导出完整 JSON 备份，或选择备份恢复。恢复前确认，替换整个当前账本。
- 应用更新：预置本项目的 GitHub 更新源，支持每天检查、通知、下载校验和系统覆盖安装；1.4.0 首次打开自动启用检查，之后保留手动开关。Android 13 及以上请允许通知，下载与安装由用户确认。安装包见 [GitHub Releases](https://github.com/Zzzsy01/local-ledger/releases/latest)，旧版接入与发布方法见 [更新发布说明](UPDATES.md)。
- 设置：按当前模式显示功能，分组管理默认主页、奶白／澄蓝／青绿配色、跟随系统／浅色／深色、金额隐藏、通知、隐私、备份、更新和使用帮助；分类、预算和导入归入记账工具。隐藏金额时也隐藏报表图形与心愿进度，避免占比透露金额。
- 备忘录：独立主页，标题、正文、搜索、全部／未完成／置顶／已完成筛选及删除；新增／编辑共享表单，当前编辑草稿可在旋转后保留，点击保存才写入数据库。
- 桌面快捷入口：设置可申请添加「记一笔」或「写备忘」图标，桌面支持时由系统确认；长按应用图标也可使用这两个快捷入口。
- 预算与固定账目：按月设置总支出预算，显示已用、剩余、超额；固定收入／支出支持按月到期、确认入账、跳过及停用。短月使用月末，下月保留原目标日。可在设置开启每天检查的系统通知；系统可能延后执行。
- 账单导入：记账工具里保存 CSV 模板，整理文件后预览再确认；支持 UTF-8 和 GB18030，事务导入，确定已导入与疑似重复分别处理。1.5.0 支持微信／支付宝常见原始 CSV 表头，仅成功收支进入预览；退款、关闭和中性交易需手动核对，详细格式见 [导入说明](IMPORT.md)。

现金、微信、支付宝、银行卡是默认账户，可修改初始余额、新增或停用。当前余额由初始余额、收支和账户转账计算；没有自动读取支付软件余额。首次使用写入默认收支分类，之后不重新写入用户已修改或停用的分类。

1.5.0 在原有本地 Lucide 图标基础上，参照 PDF 和项目链接整合笔记/待办、生活管理、财务与物品界面。来源与后续界面约束见 [DESIGN.md](DESIGN.md)。

## 构建与检查

1.7.0 采用明亮奶白、薄荷渐变、杏橙按钮与三张本地透明插画，更新主要页面的层次、悬浮导航和筛选布局。保留浅深色、澄蓝／青绿及原数据路径；发行继续使用原 GitHub 更新渠道。设计与素材见 [DESIGN.md](DESIGN.md)，验证见 [UI 升级记录](verification/ui-refresh.md)。

Android Studio 打开当前 `android` 目录，安装 SDK Platform 36 和 Build Tools 35.0.0。命令行需要 JDK 17 或 21；SDK 路径由 Android Studio 自动写入本机的 `local.properties`，该文件不提交。

Windows：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。这是本机测试安装包；后续更新必须使用相同签名与 applicationId，才能保留原账本并覆盖安装。构建时不要切换 `ANDROID_USER_HOME` 后生成另一把调试密钥；如需更改缓存位置，应先保留原调试签名。

仪器测试请使用专用模拟器或无真实账目的测试设备，Gradle 测试任务会安装、卸载应用，可能清除该设备上的账本：

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

日常试用只需连接已授权 USB 调试的手机并覆盖安装：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

测试安装时不使用 `adb uninstall`，卸载会清除本机账本。

## 代码与数据约束

- `domain`：纯 Kotlin 业务模型、整数金额与月界规则、账本完整性校验，不依赖 Android、Room 或界面。
- `data/db`：Room Entity、Dao、数据库、固定 UUID 默认数据、SQL 聚合和实体转换。
- `data/repository`：读写账本的统一入口，封装事务、关联校验、实体转换、账户偏好和备份操作。
- `data/backup`：JSON 格式编解码及系统文件读写，由 Repository 调用。
- `data/update`：更新信息解析和 Android 定时检查入口；下载、签名校验及设置由 `UpdateRepository` 管理。
- `data/importing`、`data/reminder`：有界 CSV 解析、固定账目系统提醒；导入和规划数据分别由 Repository 管理。
- `ui/home`、`ui/add`、`ui/stats`、`ui/category`：每页独立 Screen 和 ViewModel，状态只读；共用组件在 `ui/common`。
- `ui/assets`：物品列表和编辑表单，由 `AssetRepository` 读写；`ui/update` 管理更新弹窗状态。
- `ui/settings`、`ui/memo`、`ui/wishes`、`ui/planning`、`ui/importing`：设置、备忘录、心愿、预算及固定账目、CSV 预览，各自拥有 ViewModel。
- `ui/backup`：应用初始化及备份恢复的状态管理，只调用 Repository。
- 应用入口负责手动传入依赖、启动数据库以及系统文件选择器；没有单实现接口、网络服务或同步框架。

依赖边界与调用流程见 [架构说明](ARCHITECTURE.md)；开源项目参考及后续功能建议见 [后续路线](ROADMAP.md)。

金额是整数分；流水必须为正，物品可填零残值。金额输入不经过浮点转换。收支总额也保持 Long，可视图比例才使用浮点。流水软删除会更新修改时间；汇总只排除已删除流水，不排除停用分类或账户下的历史。期望月份通过本地时区的月初和下月月初转换为毫秒，SQL 使用半开区间。

新增或修改流水时验证分类类型、账户和分类有效性；已有流水仍可保留原停用项。收入、支出活动总额分别不能超过 Long.MAX_VALUE，避免 SQLite SUM 溢出。分类有关联流水（包括软删除流水）后不能改变收支类型。

## 备份格式

当前 JSON 顶层 `version: 4`，包含 `categories`、`accounts`、`transactions`、`assets`、`memos`、`budgets`、`recurringRules`、`wishes` 八个数组；保留全部字段、参考报价、导入标识、心愿进度／达成状态及软删除记录。UUID、整数金额与时间不转换、不重建；不包含账户选择偏好、默认主页、主题配色、外观和系统通知／更新设置。兼容读取版本 1、2、3：旧备份缺失的新内容（包括心愿）在完整恢复时会清空，确认弹窗显示各类数量并提醒此行为。

导出在单数据库事务中取得一致快照。恢复先解析与校验版本、字段类型、UUID 唯一性、金额、时间、关联关系与总额，再在单事务中替换数据。失败回滚，当前数据不变。恢复只接受至少一个可用账户；分类可以为空，由分类管理添加。

为了限制不可信文件的内存占用，读写均限制为 64 Mi 个字符。备份是明文文件，保存位置由系统文件选择器决定。仅导出到手机本身不能在手机丢失后恢复，建议把备份另存到电脑或用户自行选择的存储位置。

## 数据库升级

当前数据库版本为 4，通过 Room `AutoMigration(1 → 2 → 3 → 4)` 保留原数据。版本 4 新增独立 `wishes` 表，旧七表保持结构；版本 3 新增备忘录、预算、固定账目表和流水的可空唯一 `importKey`。全部版本的 schema 均保存在 `app/schemas`。迁移测试验证旧流水、物品报价、停用及软删除记录保留，并逐字段核对 3→4 的七表数据。

以后改表：提高版本，添加 AutoMigration 或显式 Migration，提交新旧 schema，并增加用旧 schema 建库、迁移、校验旧数据保留的相关测试。禁止 `fallbackToDestructiveMigration`，也不能通过删除数据库解决升级问题。

未来附件、导入来源 ID 或待确认状态按实际需求增加表／列及迁移。`source` 只是来源标记，UUID 不等于导入去重，当前未实现同步或自动记账。
