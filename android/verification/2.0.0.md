# 2.0.0 本地验证记录

本地验证日期：2026-10-11。版本 2.0.0 / 13，Android 8.0（API 26）及以上。2026-10-12 已在本地提交源码，准备发行安装包、更新说明和匹配的更新清单；尚未推送源码或发布 GitHub Release，手机自动更新渠道尚未包含本轮修改。

## 实现与兼容

- 新账支持本地商家／用途建议、低频字段折叠及“保存并继续”。连续保存保留补账日期、分类、账户和类型，每次生成独立记录；失败保留草稿，保存中阻止重复提交。编辑与采集核对沿用原保存流程。
- 分类与趋势可打开同条件账目明细；排行显示用途。当前月补充截至今天的日均及与上月相同天数比较，短月明确裁剪日期。完整区间指标保留原口径。
- 月预算补充含今天的余下天数日均额度，整数分向下取整；支出沿用整月有效流水。消费与日历进度遵循隐藏金额设置，卡片可查看本月支出。
- 今日区域展示到期／逾期待办、习惯入口、待复习数及未结束专注；待办可带入标题开始专注，计时结束不自动勾选任务。生活小结可查看对应打卡与已完成专注记录。
- 单独导出财务分析 JSON 和流水 CSV，使用系统文件选择器。事务只读取财务表；区间流水与全部有效流水计算的账面余额分别说明。金额为整数分，转账不并入收支，有记录日期不声称已记全。采集来源备注省略，不读取生活记录／照片／支付候选。分析文件有独立标识，完整恢复会拒绝它。
- 完整备份写入成功后记录时间；取消和分析导出不更新这个时间。数据库、完整备份均保持版本 6、十四张业务表；没有新增依赖或迁移。
