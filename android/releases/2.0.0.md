记账、报表、预算与今日安排的一次更新

- 新账支持本地商家／用途建议和“保存并继续”，补账时保留日期、分类、账户与收支类型；相同金额的真实消费分别保存。
- 点报表分类或趋势查看对应账目，返回后保留原位置与选择；当前月显示截至今天的日均和与上月相同天数的比较。
- 月预算显示剩余额度及含今天的每日可用额度，可直接查看本月支出。
- 备忘录今日区域集中展示到期／逾期待办、习惯、复习与未结束专注；待办可带入标题开始专注，生活小结可查看完成记录。
- 记账工具新增财务分析 JSON 与流水 CSV 导出，支持日期范围；分析文件与完整备份分开，完整备份成功后显示最近备份时间。

仍是纯本地应用，无新增服务或运行依赖。数据库和完整备份均保持版本 6；分析导出不能用来恢复完整账本。

已通过 42 项 JVM 测试、16 项 Android 仪器测试及 Android 11 模拟器操作验收；同签名从 1.7.0 覆盖到 2.0.0 后，十四张业务表共 41 条原记录的全部字段一致。Lint 无错误，仍有 17 项警告。尚未连接实体手机验证，完整 TalkBack 与不同厂商的后台及文件保存行为未覆盖。

更新前请在“设置 → 数据与备份”导出完整备份，然后直接覆盖安装，不要卸载旧版。最低支持 Android 8.0。自动检查、下载校验与系统安装确认继续使用原 GitHub 更新源。
