# PDF 参考与 1.5.0 功能整合

依据用户提供的 23 页 PDF，以及其中 [PalmNote](https://github.com/PickGear/PalmNote)、[Cashew 分支](https://github.com/wenpengcheng0413/cashew-budget-mobile-app) 的公开说明。采用页面布局和交互思路，业务实现沿用本项目的 Kotlin、Compose、Room；未复制两项目源码或将用户 PDF、评论截图放入公开仓库。

## 页面与功能对应

| 参考内容 | 本项目入口与行为 |
|---|---|
| 笔记与待办卡片 | 默认进入备忘录；笔记/待办切换，奶黄、雾蓝、浅绿、粉色，分组、搜索、排序、置顶、勾选完成、到期日期 |
| 生活计划 | 备忘录模式的「生活」；旅行预算/目的地/日期，学习与阅读目标、整数进度、完成状态 |
| 存钱与购物 | 复用「心愿」，预计价格、手动已攒金额、逐个计算剩余资金、达成归档；从生活新建菜单可直达 |
| 重要日期 | 生日、纪念日、倒计时、正数日；生日/纪念日按年重复，2 月 29 日在平年按 2 月 28 日计算 |
| 习惯与记录 | 每日打卡、补记/取消、连续天数、近 12 周记录；心情评分与日记保存，订阅金额/周期/续期日期 |
| 番茄钟 | 1–180 分钟，暂停、继续、放弃，进程重启后按持久化时间恢复；完成一次只累计一次 |
| 英语/日语学习想法 | 自建单词卡、到期复习、记得/忘记、1/3/7/14/30/60 天间隔、掌握进度；未内置外部词库或整套课程 |
| 周报/月报 | 账本已有真实收支统计；生活页新增本周/本月打卡、专注、日记、心情、近期复习卡片和已完成计划统计。按用户选择暂不接入 AI |
| 账户、转账、报销 | 账户初始余额/改名/停用；转账同时更新两账户且不计入收支、预算、报表笔数；商家、地点、待报销/已报销及管理筛选 |
| 首页、账单日历、快捷记账 | 账户余额与持有物品估值分别显示；月份概要、预算、常用账目复制、月历/周历、记录点、收支热力与选定日明细 |
| 物品列表与卡片 | 列表/两列网格；状态、类别、排序、名称/位置搜索，数量、获取方式、购入总成本/日期/渠道、位置、保修、处置日期、日均成本、最多四张本机照片 |
| 桌面待办 | 可调整大小的小组件，根据尺寸显示 1–3 项；点击勾选完成、添加待办、打开完整列表；应用锁开启时隐藏内容 |
| 设置 | 奶白/澄蓝/青绿与明暗外观；系统凭据应用锁；到期待办、重要日期、订阅、保修和固定账目每日提醒；回收站；完整备份；原 GitHub 自动更新 |
| 评论里的账单文件导入 | 识别模板、微信和支付宝常见 CSV 表头，支持 UTF-8/GB18030、预览、稳定交易号去重；只导入成功收支，退款、关闭、中性交易留待手动核对 |
| 评论里的截图识别 | 打包中文识别模型，图片文字在本机识别；可修正文字、进入账目表单核对。多个金额不明确时留空 |
| 自动记账设置 | 默认关闭。用户在系统授予通知使用权后，只采集微信/支付宝明确成功的支付通知，进入候选列表；确认入账和候选处理使用同一事务 |

备忘录与记账仍是独立导航，备忘录模式不注册账户、账单、物品、预算或报表页面。链接 README 额外列出的密码本、全库加密、多账本/多币种、云同步等能力尚未并入本版；界面不放置没有实际功能的入口。

## 数据边界

- Room/JSON 备份升为版本 5，兼容旧版 1–4；迁移保留旧八表，新增四张生活表和支付候选表。
- 图片导入即复制到应用私有目录；备份包含照片字节，恢复先验证图片，再事务替换记录。无效附件和无效引用不覆盖现有数据。
- 单张照片上限 20 MB；完整 JSON 上限 64 Mi 字符，照片合计上限 48 MB；超限明确停止导出，不生成缺照片的备份。
- 物品的数量只参与件数；购入成本、估值是该条记录总额。已清出物品不计入持有估值，日均成本截止处置日，缺购入日期时不推算。
- 订阅只推进续期日期，不自动扣款或生成账目；每月 29–31 日保留原始目标日，避免短月之后漂移。
- 应用锁使用手机锁屏凭据；本版完整备份为明文 JSON，不宣称已实现数据库或备份加密。
- 通知权限和后台调度由 Android 管理；提醒为每日检查，可能受省电影响。无法恢复支付软件未发送或已被系统移除的通知。
- 生活总结的「复习过的单词」按卡片最近复习日统计，「已完成计划」按本期更新且已完成的记录统计，标签与数据口径一致。

技术依据：[ML Kit 打包中文识别模型](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)、[Android 通知监听服务](https://developer.android.com/reference/android/service/notification/NotificationListenerService)、[Android 系统锁屏凭据确认](https://developer.android.com/reference/android/app/KeyguardManager)。
