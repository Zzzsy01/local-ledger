# CSV 账单导入

设置 → 导入账单 CSV → 保存 CSV 模板。首版支持本应用模板，微信／支付宝的原始导出请先整理成这些列，不直接解析各平台所有导出格式。

```csv
时间,收支,金额,分类,账户,备注,来源ID
2026-10-01 12:00:00,支出,25.50,餐饮,微信,午餐,
2026-10-02,收入,3000,工资,银行卡,月工资,pay-2026-10
```

时间、收支、金额三列必需，其他列可省略或留空。时间为设备本地时间，格式 `yyyy-MM-dd` 或 `yyyy-MM-dd HH:mm:ss`；结束日期筛选包含当日。收支只接受“收入”“支出”，金额为正数的元、最多两位小数；没有转账类型，整理文件时先排除账户间转账。

分类与账户填写应用内名称；分类必须与收支类型相同且可用，重名或不存在会提示行号，先修改文件或在设置创建分类。留空时用导入页选择的默认收支分类和账户。备注含逗号、换行或引号时按 CSV 规则加双引号，内部引号写两次。文件支持 UTF-8（含 BOM）和 GB18030，可切换编码后重选。

预览不写入数据库；确认后整批用一次事务写入，任何金额溢出、关联无效或写入失败均回滚。一次最多 10000 笔、8 MiB 文件。导入不会修改已有账目，来源标为 1。

有来源 ID 时，以支付账户与来源 ID 确定已导入记录；来源 ID 需在同一账户来源里唯一，不要混用不同平台会重复的短序号。无来源 ID 时，以原文件 SHA-256 和行号识别重选同一文件。导入标识保留在备份与软删除记录中，删除后重选文件不会自动恢复已删账目。

金额、收支、时间、备注相同属于“疑似重复”，默认跳过；确认确实是不同账目时可以关闭“跳过疑似重复”。改过文件而且没有稳定来源 ID 时，不能仅靠文件标识可靠去重，务必核对预览。来源标识已确定重复的记录始终跳过。

## 1.5.0 支付账单与截图

可直接识别微信的「交易时间、收/支、金额(元)」及支付宝的「交易创建时间、收/支、金额（元）」等常见 CSV 表头，跳过文件前导说明。自动使用微信/支付宝同名可用账户，分类使用导入页默认选择；稳定交易号加平台前缀用于去重。成功收支之外的关闭、退款、中性记录不自动转换；有成功退款金额的记录也跳过，预览明确提示核对。特殊导出格式或 XLSX 请先转换为模板 CSV，不能仅修改扩展名。

「截图与自动采集」使用本机打包中文模型识别。文字可修改，金额明确时填入表单，多个价格没有明确实付字段时留空。支付通知采集默认关闭且需要系统授权；只采集微信/支付宝的明确成功通知，确认分类、账户、时间和金额后才入账，已处理候选不能再次确认。截图/通知账目来源为 2，CSV 为 1。
