# 我的博物馆与功能导航

## 去哪里找功能

- 顶部切换「备忘录 / 记账」，两种模式各自保留页面与筛选，默认仍进入备忘录。
- 备忘录底栏：备忘录、生活、博物馆、心愿。笔记与待办在备忘录中切换。
- 记账底栏：账单、报表、博物馆、工具。工具分资金管理（账户、预算固定账目、报销）和账单整理（截图采集、CSV、分类）。
- 生活分日常、计划、日期、学习、总结；搜索跨生活分组，新建按所在分组提供类型。习惯、心情、日记在日常；订阅在日期；番茄钟和单词卡在学习。
- 顶部放大镜是跨两种模式的物品搜索；设置齿轮集中外观、提醒、隐私、备份、回收站、桌面入口和更新。

## 为物品建立档案

博物馆 → 添加物品。可以先只填写名称和位置，逐步补充照片、购入总价与日期、获取渠道、标签别名、序列号、保修日期及物品故事。收藏展柜用于展示喜爱的物品；待整理筛选找出缺少位置、购买日期或购入价的档案。

位置可写成「家 / 书房 / 白柜 / 第二层」，借出时可写当前保管人。搜索支持多个空格分隔的关键词，同时匹配名称、标签、编号、渠道、购买日期、故事和历史记录。匹配旧位置时明确提示历史匹配，结果仍显示当前位置。这里的全局搜索专指物品，不会混入账单或笔记搜索结果。

点击物品进入独立藏品档案，查看位置、买价、当前估值及估值日期、相对买价变化、持有天数、日均购入成本、保修和照片。

## 流转与价值记录

移动位置、更新估值、修改购买信息或状态，会在保存物品的同一数据库事务中写入历史。可添加和编辑随记、使用、保养、借还记录；借还手记不自动修改当前位置，请同时更新位置或保管人。自动历史不可修改，旧版未记录过的历史不会补造。

估值由用户填写或根据手动录入的挂牌参考价求均值，不是实时市场报价。留空表示未知，填写 0 表示确认无残值；合计只统计已填估值。购入成本与当前估值独立，不自动修改账户余额或生成账单。

## 数据与升级

Room 5→6 保留原有十三张表，新增资产记录表及标签、编号、收藏、估值已知标记。旧资产沿用已有估值，历史初始为空。

完整 JSON 备份版本 6 包含物品档案、照片和全部历史，支持读取版本 1–5。恢复旧备份时，新字段采用默认值、历史为空，且替换当前全部数据；恢复前请先备份。删除物品后历史随物品隐藏，回收站恢复物品后重新显示。
